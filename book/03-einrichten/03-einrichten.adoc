== Einrichten der Arbeitsumgebung

Nachdem wir uns eingehend mit der Joomla!-Geschichte beschäftigt haben,
machen wir uns nun an die Arbeit. Bevor du jedoch mit der Installation
deiner Joomla!-Umgebung loslegen kannst, gibt es noch ein paar vorbereitende Schritte.
In diesem Kapitel richtest du deine Arbeitsumgebung ein – gewissermaßen deine persönliche „Werkstatt”.

Für die Arbeit mit Joomla! brauchst du vor allem vier Programme:

* die Programmiersprache _PHP_, um den Joomla!-Programmcode auszuführen,
* eine Datenbank, um Konfigurationen und Inhalte abzulegen,
* einen _Webserver_, um die dynamisch, mit PHP erzeugten Joomla!-Seiten auszuliefern und
* einen _Quelltext-Editor_, um die HTML-, CSS-, JavaScript- und PHP-Dateien zu bearbeiten.

Diese Arbeitsumgebung kannst du bei einem Hoster als zusätzliche Test-Instanz einrichten.
Oder, falls du bereits mit Docker oder Podman vertraut bist,
kannst du das offizielle Joomla! 6.0 Image als Container installieren.
Oder – falls du nur die Administration üben möchtest – kannst du eine kostenlose Joomla!-Instanz unter
https://launch.joomla.org erstellen.

Wir empfehlen und beschreiben in diesem Kapitel den Aufbau einer lokalen Arbeitsumgebung auf dem eigenen Computer.
Du kannst die Einrichtung entweder unter Ubuntu Linux 24 LTS, macOS oder Windows 11 vornehmen.

IMPORTANT: Die Einrichtung der lokalen Arbeitsumgebung erfolgt für das Testen und die Entwicklung.
           Es werden keine Sicherheits- oder Performance-Anforderungen berücksichtigt.
           Die Arbeitsumgebung ist ausdrücklich nicht für den produktiven Einsatz im Internet geeignet.

Für unser Joomla! 6.0 Test-Umgebung verwenden wir:

* PHP in der Version 8.4, als die für Joomla! 6 empfohlene Version,
* MariaDB als Open Source Datenbank,
* die freie Webanwendung phpMyAdmin für die Administration der Datenbank,
* Apache HTTP Server als Open Source Webserver und
* Microsoft Visual Studio Code (VS Code) als OpenSource Quelltext-Editor.

Abschließend geben wir in diesem Kapitel einen kurzen Einstieg in die
Web Developer Tools, als Browser-Werkzeug in Mozilla Firefox.

*Kommandos im Terminal*

Wenn in den folgenden Beispielen ein Kommando im Terminal ausgeführt werden soll,
verwende bitte Kopieren und Einfügen (Copy & Paste), um Tippfehler zu vermeiden.
Bei mehreren aufeinanderfolgenden Kommandos bitte Zeile für Zeile kopieren
und achte jeweils auf eine fehlerfreie Ausführung der Kommandos.
Das folgende Beispiel sind zwei einzelne Kommandos:

[console,opts=keep-together]
----
hostname
uptime
----

Wenn eine Zeile mit einem Backslash (`\`) endet,
musst du immer auch die nächste Zeile mitnehmen – sonst fehlt dir ein Stück vom Befehl.
Mit anderen Worten: Alle Zeilen, die mit einem `\` enden, gehören zusammen zu einem Kommando.

Hier ein Beispiel: Das folgende Kommando wird in drei Zeilen dargestellt und
du musst es komplett in einem Stück kopieren:

[console,opts=keep-together]
----
echo "Das ist eine längere Zeile, für das Buch, \
      die sich mit Backslashes \
      jeweils in die nächste Zeile rettet."
----
